Ajuda

Como usar o APP

  • Clique no botão "Sobre" para ver informações sobre o desenvolvedor
  • Clique no botão "Ajuda" para abrir esta janela de ajuda
  • Clique no botão "Calculadora" para abrir a calculadora

Informações

Este é um aplicativo simples desenvolvido com Electron, uma framework que permite criar aplicações desktop usando tecnologias web como HTML, CSS e JavaScript.

Características

  • Interface intuitiva e fácil de usar
  • Desenvolvido com tecnologias web modernas
  • Design responsivo e limpo
  • Cross-platform (funciona em Windows, Mac e Linux)
  • Calculadora com 4 operações básicas

Suporte

Se você tiver alguma dúvida ou encontrar algum problema, entre em contato através do perfil do desenvolvedor na seção "Sobre".
